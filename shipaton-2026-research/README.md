## Run 7 — UX architecture, journey, and attention

Run 7 compares complete Restart Thread flows. Its controlling revision
recommends Instant Voice Thread: local-first audio capture, a grounded AI
recovery draft, conditional Lock Screen entry, Context + Voice as an alternate
entry, and Voice Rescue as the fallback. It preserves the broader journey,
state, accessibility, monetization, and usability work without selecting visual
styling.

## Run 10 — platform, architecture, and ship scope

Run 10 selects one native Kotlin and Jetpack Compose Android project with
Play and conditional Galaxy product flavors. It defines device and server data
ownership, RevenueCat and no-account flows, privacy, failure budgets, tests,
operations, a traced vertical slice, a dated two-store critical path, and the

## Run 11 — validation, instrumentation, and submission story

Run 11 connects the selected product to observable user, release, and judging
proof. It defines a five-participant formative study, privacy-safe event and
first-action instrumentation, criterion-level judge evidence, a 1:58 target-
device demo, submission production, and a milestone-based BuildInPublic
calendar. RevenueCat Design is primary; Galaxy and OneSignal remain conditional
on live proof. The builder approved Option A on August 12, 2026.

Add future stages as `Run-N/`. Store the primary narrative as `report.md`, keep
run-specific evidence beside it, and update the shared state and this index only
after the run is complete.
