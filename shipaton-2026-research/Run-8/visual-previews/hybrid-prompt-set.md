# Hybrid visual-prototype prompt set

The two boards were generated with the built-in image-generation tool using the
A2, A3, A4, and corrected A5 boards as visual references. The references were
assigned narrow roles and were not edit targets or assets to collage.

## H1 — Anchor Forward

```text
Create a four-zone hybrid brand and interaction board for Restart Thread with
A2 as the dominant identity. The large dot means where I am now; an interrupted
dotted path means context preserved; a forward arrow means the one next action
I choose.

Show four vector-friendly marks; the A2 violet color and system-sans type
system; an Android hero with one restrained tactile Start here action; one
privacy-safe Recording lock-screen widget; and four keyframes of the first A2
Trace-back variation ending in one direct evidence connector. The route is
supplemental to labels and node shapes.

Avoid Spotify ribbon or Wrapped composition, infinity or refresh loops, media
play, navigation pin, AI sparkles, microphone as the main logo, therapy or ADHD
diagnostic imagery, planner or game mechanics, glass, neon, trademarks, and
private locked content.
```

## H2 — Forward Thread

```text
Create a four-zone hybrid brand and interaction board for Restart Thread with
A4 as the dominant identity, integrating A2's large focal dot and dotted
evidence path. An open form acknowledges interruption; the dot marks the
recovered present position; an arrow moves one verified action forward.

Show four vector-friendly open-boundary, dot, path, and forward-notch marks;
the A4 paper, ink, and editorial-red system; restrained serif display with
system-sans controls; one tactile Start here action; one privacy-safe Recording
widget; and four keyframes of the direct Trace-back connector with a static
reduced-motion result.

Avoid a quotation-only, crop, scan, camera, browser-forward, media-play, or
messaging mark; avoid Spotify trade dress, AI sparkles, therapy or diagnostic
imagery, planner or game mechanics, glow, glass, trademarks, and private locked
content.
```
