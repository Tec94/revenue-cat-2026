# Run 2 report: project dossiers and matched controls

## Executive summary

Run 2 is complete for the selected Option A sample. Eighteen winners from 2024
and 2025 were analyzed in five batches of no more than four, with one explicit
winner-to-control comparison per dossier. The analysis uses 16 unique plausible
non-winning controls because PCOS Polly and Memory Hammer each provide a useful
match in two different dimensions.

Every winner dossier covers the requested twelve dimensions, includes a
predicted—not measured—attention map where event-period visuals permit it, and
ends with supported findings, unknowns, and possible 2026 transfer. Every
historical criterion has evidence, counterevidence, confidence, and a 1–5
analyst score. No score is represented as the judges' score.

The deliverable stops at the required gate. Twelve candidate patterns are now
defined as testable propositions, not conclusions. None has been tested across
the 39-winner corpus, accepted as a differentiator, used to choose an award, or
used to generate an app concept.

### Tool and fallback log

Exa was the primary system for discovery and full-text extraction of every
important known page. Firecrawl was used for dynamic Devpost links and asset
recovery. Vision was used only after those systems could not establish visual
hierarchy, contrast, gesture emphasis, or screen layout. The visual fallback
inspected downloaded event-period assets; it did not infer analytics,
eye-tracking, or interaction heatmaps.

Notable fallbacks or inaccessible artifacts:

- Payout's embedded event video is currently private; the Devpost page,
  screenshots, official recap, and reported metrics were used.
- MoodHaven's primary video timed out during extraction; its contemporaneous
  screenshots, Devpost text, and silent supplemental video were used.
- Echo Reminder had no separate Devpost screenshot gallery; its event video
  transcript and video thumbnail supplied the visual evidence.
- Cooked This had no separate Devpost images; one event demo frame was inspected.
- Rangelert's submission contained brand banners but insufficient working-screen
  evidence for a detailed interaction audit.

## Contradictions and missing evidence

The following issues remain material for later pattern testing.

- Non-winner category selections are generally not public. Controls are
  reasonable matches, not proven entries in the same award.
- One Step's 2024 match is inferred from screen dates, asset timing, and event
  language because its challenge backlink is missing.
- The historical events disclose no raw judge scores, deliberations, or
  standardized analytics. Analyst scores cannot reconstruct them.
- Builder metrics use different snapshots. Examples include Gurwi's official
  13,000+ user recap versus its October 3 update, PCOS Polly's September 30
  $3,500 ARR versus October 7 $11,100 ARR, and Momental's 4,200 reported
  sessions versus the recap's rounded 4,000+.
- Reach is not engagement, downloads are not active users, sessions are not
  unique people, and follower counts are not views. The dossiers preserve those
  distinctions.
- PitchLab had almost two years of prior development; the event artifact is its
  first public release, not a two-month invention. Heartbeat Hero similarly
  rebuilds a previously unshipped 2024 student prototype.
- Restia's available gallery includes later updates. Post-event material is not
  assumed to be what judges saw.
- Several high-stakes claims lack independent validation: Heartbeat Hero depth
  accuracy, Hearing Buddy word/diarization accuracy, MoodHaven clinical value,
  PCOS Polly advice, Vector Guard's realized subsidy impact, and ReadHim's
  relationship guidance.
- Empty, loading, error, permission-denied, cancellation, deletion, restore,
  and offline-recovery states are underrepresented in submission media across
  both winners and controls.
- Accessibility evidence is uneven. A feature described as inclusive is not
  treated as tested accessibility unless VoiceOver, Dynamic Type, input
  alternatives, or comparable evidence is visible.
- Current store listings may contain post-event redesigns, packages, or prices.
  They are not used to reconstruct historical judge-visible UI.

## Recommendation

Choose a balanced set of eight candidates unless the next run has a narrower
question. The balanced set covers product coherence, user evidence, business
fit, submission observability, and risk without over-weighting a single award
family. It also contains propositions that the matched controls can plausibly
falsify.

Run 3 should then code the selected candidates across the full 39-winner corpus
and matched controls, define positive/negative evidence before scoring, separate
2024 from 2025 criteria, and reject any proposed differentiator that occurs as
often in controls. It should not select an app concept or primary 2026 award.
