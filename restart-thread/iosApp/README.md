# Legacy iOS scaffold

This directory preserves the earlier Kotlin Multiplatform host experiment for
reference. It is not the supported Apple application and must not be used for
new builds.

Use `../apple` for the complete native iOS and macOS implementation, shared
Swift package, WidgetKit targets, XcodeGen project, tests, assets, Auth0, and
RevenueCat integration. Follow `../apple/README.md` for setup and verification.

The template and example configuration remain only to document the abandoned
host direction. Don't add credentials or generate an Xcode project here.
