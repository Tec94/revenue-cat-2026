# Logo assets

These SVGs reconstruct the four Logo Lab marks in the locked Forward Thread
prototype. They use geometry rather than raster tracing, so they remain crisp
and editable. The artwork defaults to Ink (`#111111`). In an inline SVG,
change the root `color` value to use a semantic foreground token.

| Asset | Prototype position | Intended use |
|---|---|---|
| `mark-01-open-thread.svg` | Upper left | Full product story; primary candidate for large brand and onboarding surfaces |
| `mark-02-corner-thread.svg` | Upper right | Balanced app-icon candidate with a quieter boundary |
| `mark-03-split-boundary.svg` | Lower left | Bold editorial/store candidate; highest crop/focus-symbol risk |
| `mark-04-compact-forward.svg` | Lower right | Small-size and generic locked-surface candidate |
| `wordmark-stacked-editable.svg` | Brand-system wordmark | Editable reconstruction; the prototype does not identify the exact serif |
| `lockup-horizontal-editable.svg` | Derived lockup | Open-thread symbol plus editable wordmark |
| `logo-sheet.svg` | Derived overview | Review and comparison only |

## Important status

The prototype contains four explorations, and no source records a final choice
among them. Do not quietly turn the first cell into a permanent app icon.
Recommended testing is `mark-01` as the expressive primary and `mark-04` as the
small-size companion, with recognition and similarity checks at the actual
store and launcher sizes.

The editable wordmark uses a Georgia/Times fallback stack because the image
shows a high-contrast editorial serif but supplies no font metadata. Outline a
licensed final typeface before distributing the wordmark as immutable artwork.

Avoid treating the arrow alone as the brand; it can read as media play or
browser navigation. Preserve at least the present-state dot and context cue.
