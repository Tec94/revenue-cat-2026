# Reference

`forward-thread-prototype.png` is the 1536 × 1024 visual board supplied by the
builder on August 12, 2026. It contains:

1. four monochrome logo explorations;
2. the paper, ink, gray, action-red, dark-accent, and dark-surface palette;
3. a dark Android hero with the tactile **Start here** action;
4. a privacy-safe generic recording surface; and
5. I2-V1 Direct Trace-back Connector states, including reduced motion.

The static image can establish composition and visual intent. It cannot prove
exact font files, dimensions, easing curves, haptic patterns, audio, contrast
after platform conversion, or physical locked-surface behavior. Those items in
`DESIGN.md` are explicitly sourced from the accepted research specification or
labeled as reconstructed starting values.
